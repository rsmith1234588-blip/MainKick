Editor

Make it your own.

A scratchpad that lives inside Mainkick, so nothing gets lost between tabs.

  • Press ✎ → Editor on any answer to drop it into your draft.
  • Rewrite it in your own words. It autosaves as you type.
  • Live word and character counts.
  • Copy, Read, download as .txt or .md.
  • Insert into page puts the whole draft into the text box you last clicked, all at once, just like a paste.

Install

Up and running in 4 steps.

Mainkick isn't on the Chrome Web Store, so you load it yourself. It takes a minute.

  1. Download and unzip

    Get mainkick.zip and unzip it. You'll get a folder called mainkick. Keep it somewhere it won't be deleted.

  2. Open the extensions page

    Type chrome://extensions in the address bar (Edge: edge://extensions).

  3. Turn on Developer mode

    Flip the Developer mode switch in the top-right corner.

  4. Load unpacked

    Click Load unpacked and pick the mainkick folder. Pin the green M from the puzzle-piece menu.

Setup

Add your free key.

Mainkick talks to Groq with your own key. It's free and takes a minute.

> open console.groq.com/keys # sign in, then “Create API key”
> copy the key # it starts with gsk_
> click the Mainkick icon → ⚙ → paste → Save settings
> ready_

Privacy

Your data stays yours.

No accounts, no tracking, no servers of ours. Your key, chats, drafts and memories stay in your browser's extension storage. Messages go only to Groq when you send them, and page text is sent only when you tick “Attach this page”.
